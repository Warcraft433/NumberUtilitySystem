# Number Utility System

## 📌 Overview

A menu-driven Core Java console application that performs various number-related operations and calculator functions.

---

## 🚀 Features

- Prime Number
- Armstrong Number
- Palindrome Number
- Strong Number
- Perfect Number
- Reverse Number
- Fibonacci Series
- Factorial
- Calculator

---

## 🛠 Technologies Used

- Java
- Eclipse IDE
- Git
- GitHub

---

## 📂 Project Structure

```
src/
│
├── com.numberutility.app
│      NumberUtilityApp.java
│
└── com.numberutility.service
       NumberUtilityService.java
```

---

## ▶️ How to Run

1. Clone this repository.

```bash
git clone https://github.com/Warcraft433/NumberUtilitySystem.git
```

2. Open the project in Eclipse.

3. Run

```
NumberUtilityApp.java
```

4. Choose an option from the menu.
